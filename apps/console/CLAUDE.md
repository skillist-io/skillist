# apps/console — authenticated product SPA (@skillist/console)

The authenticated **product** → `console.skillist.io`: dashboard, inventory, observability, governance, settings, account, admin, projects, skill editor, and `/login`. (The public marketing site is a separate app, `apps/web` → skillist.io.) React 19, Vite 8, TanStack Router (file-based) + Query, Tailwind v4. Better Auth client + passkeys.

## Conventions

- **Routes**: bare authenticated routes (`/dashboard`, `/inventory`, `/observability`, `/governance`, `/settings`, `/account`, `/orgs/...`, `/admin/...`) plus `/login`. Defined in `src/routes/*.tsx` via `createFileRoute("/path")({ beforeLoad, component })`; auth-gate with `requireAuth()` (`@/lib/require-auth`). **Never hand-edit `src/routeTree.gen.ts`** — it's generated by TanStack Router.
- **Shared UI + clients**: import primitives, shared components, and clients (`api`, `auth-client`, `theme`, `consoleUrl`/`webUrl`, `cn`) from **`@skillist/ui`** (the shared design system, consumed as source) — not local `components/ui` or `lib`. Cross-app links to the marketing site use `webUrl()`. New app-specific primitives still follow the design system.
- **Data**: use the `api<T>(path, init)` wrapper from `@skillist/ui` (`credentials: "include"`, throws on non-ok). Reads via TanStack Query; `invalidateQueries` after mutations.
- **Bundle editor**: the editor cluster is `src/components/skill-editor/*` (colocated `*.test.tsx`).
- **Styling/tokens**: shared tokens/styles come from `@skillist/ui` (`styles.css`, `@theme inline`, OKLCH grayscale tokens, `.dark`, `@custom-variant dark`). Prefer tokens over literal colors.

## Design system (identity — do not drift toward stock shadcn)

"The Control Surface": squared geometry (0 radius), monochrome ink + exactly two accents (destructive **red** = failure, signal **violet** = live), text-only badges, underline inputs, hairline rings not shadows. **WCAG 2.2 AA in both light and dark**; never status-by-color-alone. Full detail: `DESIGN.md` / `PRODUCT.md`. → skill: `/design-system`, agent: `web-ui-builder`. Live visual iteration: `/impeccable`.

## Dev / test

- `pnpm dev:console` (:5174). The Vite dev server proxies `/api`, `/v1`, `/docs`, `/openapi.json`, and the apex `/{org}/{repo}/...` paths to `:8787` — that proxy's path regex mirrors the API's apex auth regex; keep them in sync. In production the app is a Cloudflare Worker (`src/worker.ts`) with a **service binding** to the API worker, proxying the same paths same-origin (session cookie scoped to `.skillist.io`, so no CORS/cross-subdomain complexity).
- Tests: Vitest + jsdom + Testing Library. One file: `pnpm --filter @skillist/console exec vitest run <path>`.
