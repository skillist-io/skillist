## What is Skillist?

Skillist is a platform for managing, versioning, and delivering [agentskills.io](https://agentskills.io/home) skills with sub-10ms fan-out, hosted sandboxes, evals, and a public registry.

<CardGrid stagger>
  <Card title="Registry MCP" icon="puzzle">
    Search and install skills from your agent via streamable HTTP at
    `api.skillist.dev/mcp`.
  </Card>
  <Card title="CLI" icon="rocket">
    Install skills locally with `skillist install org/slug` and publish from your
    repo.
  </Card>
  <Card title="Hosted execution" icon="laptop">
    Run skill scripts in isolated Cloudflare sandboxes with streaming output.
  </Card>
  <Card title="Evals" icon="approve-check">
    Measure skill uplift across versions before publishing to the registry.
  </Card>
</CardGrid>
