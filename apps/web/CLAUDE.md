# apps/web — React SPA (@skillist/web)

React 19, Vite 8, TanStack Router (file-based) + Query, shadcn/ui, Tailwind v4. Better Auth client + passkeys.

## Conventions

- **Routes**: `src/routes/*.tsx` via `createFileRoute("/path")({ beforeLoad, component })`; auth-gate with `requireAuth()` (`@/lib/require-auth`). **Never hand-edit `src/routeTree.gen.ts`** — it's generated by TanStack Router.
- **Data**: use the `api<T>(path, init)` wrapper (`@/lib/api.ts`, `credentials: "include"`, throws on non-ok). Reads via TanStack Query; `invalidateQueries` after mutations. Shared response types live in `api.ts`.
- **Components**: reuse `src/components/ui/*` (shadcn primitives) and `cn()` (`@/lib/utils`). New primitives use `cva`. The bundle editor cluster is `src/components/skill-editor/*` (colocated `*.test.tsx`).
- **Styling/tokens**: `src/index.css` (`@theme inline`, OKLCH grayscale tokens, `.dark`, `@custom-variant dark`). Prefer tokens over literal colors.

## Design system (identity — do not drift toward stock shadcn)

"The Control Surface": squared geometry (0 radius), monochrome ink + exactly two accents (destructive **red** = failure, signal **violet** = live), text-only badges, underline inputs, hairline rings not shadows. **WCAG 2.2 AA in both light and dark**; never status-by-color-alone. Full detail: `DESIGN.md` / `PRODUCT.md`. → skill: `/design-system`, agent: `web-ui-builder`. Live visual iteration: `/impeccable`.

## Dev / test

- `pnpm dev:web` (:5173). The Vite dev server proxies `/api`, `/v1`, `/docs`, `/openapi.json`, and the apex `/{org}/{repo}/...` paths to `:8787` — that proxy's path regex mirrors the API's apex auth regex; keep them in sync.
- Tests: Vitest + jsdom + Testing Library. One file: `pnpm --filter @skillist/web exec vitest run <path>`.
