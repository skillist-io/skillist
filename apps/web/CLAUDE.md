# apps/web — public marketing SPA (@skillist/web)

The public **marketing** site → `skillist.io`: landing, registry browse, and public skill pages `/{org}/{repo}`. (The authenticated product is a separate app, `apps/console` → console.skillist.io.) React 19, Vite 8, TanStack Router (file-based) + Query, Tailwind v4.

## Conventions

- **Routes**: `src/routes/*.tsx` via `createFileRoute("/path")({ ... })` — the landing (`index.tsx`), `registry/` browse, and public skill pages under `$org` (`/{org}/{repo}`). These are public reads; no auth gate. **Never hand-edit `src/routeTree.gen.ts`** — it's generated by TanStack Router.
- **Shared UI + clients**: import primitives, shared components, and clients (`api`, `theme`, `consoleUrl`/`webUrl`, `cn`) from **`@skillist/ui`** (the shared design system, consumed as source) — not a local `components/ui` or `lib`. Links into the authenticated product (e.g. "sign in", "manage") use `consoleUrl()`, keyed off `VITE_CONSOLE_URL`.
- **Data**: use the `api<T>(path, init)` wrapper from `@skillist/ui`. Reads via TanStack Query.
- **Styling/tokens**: shared tokens/styles come from `@skillist/ui` (`styles.css`, `@theme inline`, OKLCH grayscale tokens, `.dark`, `@custom-variant dark`). Prefer tokens over literal colors.

## Design system (identity — do not drift toward stock shadcn)

Same "Control Surface" identity as the console: squared geometry (0 radius), monochrome ink + exactly two accents (destructive **red** = failure, signal **violet** = live), text-only badges, hairline rings not shadows. **WCAG 2.2 AA in both light and dark**; never status-by-color-alone. The marketing surface earns attention through substance, not spectacle. Full detail: `DESIGN.md` / `PRODUCT.md`. → skill: `/design-system`. Live visual iteration: `/impeccable` (live mode targets `apps/web/index.html`).

## Dev / test

- `pnpm dev:web` (:5173). The Vite dev server proxies `/api`, `/v1`, and the apex `/{org}/{repo}/...` delivery paths to `:8787`. In production the app is a Cloudflare Worker (`src/worker.ts`) with a **service binding** to the API worker, proxying the same paths same-origin — no CORS or cross-subdomain-cookie complexity.
- Tests: Vitest + jsdom + Testing Library. One file: `pnpm --filter @skillist/web exec vitest run <path>`.
