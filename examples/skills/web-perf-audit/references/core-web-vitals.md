# Core Web Vitals

Google's Core Web Vitals measure real-user experience quality.

## LCP — Largest Contentful Paint

Time until the largest above-the-fold content element renders. Good: ≤ 2.5s.

## INP — Interaction to Next Paint

Responsiveness to user input (replaces FID). Good: ≤ 200ms.

## CLS — Cumulative Layout Shift

Visual stability — unexpected layout movement. Good: ≤ 0.1.

## Supplementary metrics

- **FCP** — First Contentful Paint
- **TBT** — Total Blocking Time (lab proxy for interactivity)
- **Speed Index** — how quickly content is visually populated

Load this file when explaining metrics to the user or classifying audit results.
